# Dribble Motion Lab

A first browser-based prototype for a reusable motion-graphics creator.

## Try it
Open **index.html** locally, or enable GitHub Pages for the repository to host it as a website.

## Current prototype
- Editable headline/subject
- Six motion presets: cinematic reveal, 3D orbit, kinetic typography, neon, glitch, and minimal
- Four color palettes
- Toggleable particles, orbit lines, glow, and grid
- 5/8/10/15-second target duration setting
- Replay and pause controls
- Responsive layout

## Important limitations
This is a visual prototype, not an AI video generator yet. It currently previews CSS animations in the browser; it does not import or extract assets from Dribbble, train a model, or export MP4 files. Use reference projects to study general techniques, and only reuse original assets when you have permission or an appropriate licence.

## Planned next stages
